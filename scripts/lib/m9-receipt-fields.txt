# Required field paths of a valid M9 Gate 2 closure receipt (PASS only).
#
# Dotted paths are resolved against the receipt JSON document by
# scripts/verify-m9-closure-receipt.py. A field must be present; explicit JSON
# null is acceptable only where the verifier's semantic rules allow it.
#
# The field `terminal_line` is deliberately NOT part of this schema and is
# rejected if present: the formal RC terminal marker is emitted exactly once by
# the wrapper process, it is not embedded in the receipt.
#
# cross_binding.* mirrors the sealed digests in both directions so a receipt can
# never be self-consistent while pointing at archive/index bytes that were
# re-derived or mutated after sealing.
#
# authorization_sha256 is the SHA-256 of the exact Human-issued authorization
# TOKEN string and is deliberately NOT the digest of the issued document.
# issued_document_sha256 carries the exact issued-document byte identity as a
# separate, semantically distinct receipt field computed by the wrapper over the
# retrieved bytes. It is never demanded from inside the document, because a
# document can never contain a correct digest of its own bytes.
