# Required execution artifacts for an M9 Gate 2 formal closure (PHASE A).
#
# The contract is an EXPLICIT canonical relative-path set. Paths are relative to
# the formal evidence directory and are compared as a set:
#
#   actual regular files (minus artifact-manifest.sha256) == this exact set
#
# Blank lines and lines beginning with '#' are ignored deterministically. Every
# other line must be a canonical relative path: absolute paths, '.', '..', any
# '..' traversal component, empty components, './' prefixes, backslash
# separators and shell-style globs are all rejected, as are duplicate entries.
# scripts/verify-m9-artifact-completeness.py owns that validation.
#
# These are artifacts of the EXECUTION phase only. Seal-phase outputs
# (artifact-manifest.sha256, the canonical archive, package-index.json) and the
# commit-phase closure-receipt.json are deliberately excluded: the manifest must
# not contain itself, and the archive/index/receipt are generated outside the
# evidence root after the execution phase has been validated.
